🎲 Dice Roll Chat Interface Demo

Experience the full DM → Player dice request flow with real-time chat

How it Works

1. DM makes request: Click "Request Dice Roll" and select the player, dice expression, and description.

2. Player receives notification: Player sees the request in real-time with options for advantage/disadvantage.

3. Player responds: Player rolls the dice and the result is automatically shared with everyone.

4. Results displayed: Both DM and player see the result with full breakdown and any special effects (crits, fumbles).
